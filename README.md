# FinTrust Digital Bank — Experience Lab Project

## Project Overview
This repository documents my work on the **FinTrust Digital Bank Experience Lab** project, a 4-week internship project under **AnalystLab Africa**. FinTrust is a fictional digital banking organisation using synthetic customer and transaction data for educational purposes.

**My track:** Data Analytics

The project's goal is to turn FinTrust's customer and transaction data into actionable business intelligence — supporting management decisions, risk monitoring, and digital customer support through structured analysis and dashboards.

## Tools Used
Excel · SQL Server (SSMS) · Python (Pandas, Seaborn, Jupyter via VS Code) · Power BI

## Key Findings So Far
- International transactions carry nearly double the risk-flag rate of domestic ones — and this compounds further on ATM specifically (46.0%)
- USSD has the highest transaction failure/reversal rate (~10%) — a targeted reliability gap, not a platform-wide issue
- Customer segment is a weak differentiator for both risk and value — transaction-level factors (channel, international status, value) matter more
- Everyday customers drive the most transaction value and volume — the core of FinTrust's business

## Data
The datasets (`FinTrust_Customer_Data`, `FinTrust_Transaction_Data`) are **synthetic**, created by AnalystLab Africa for educational purposes only — they do not represent real customers or transactions.

- Customer_Data: 1,501 rows (incl. header)
- Transaction_Data: 12,001 rows (incl. header)
